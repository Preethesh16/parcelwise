Connect an ecommerce site or partner API

Send a confirmed order to POST /api/integrations/orders with the company key in X-API-Key. Repeated order IDs with the same payload return the existing order without another charge.

Partners send POST /api/integrations/delivery with their own key and {"orderId":"PW-…","partnerId":"B","stage":1}. Only the selected partner can progress its delivery, in sequence.
